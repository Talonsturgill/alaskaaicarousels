HB 259, state utility standards for large data centers

HB 259, introduced by Rep. Donna Mears in January 2026, would set utility rate-setting guidelines and community benefit standards for large energy use facilities such as data centers. It was referred to the House Energy Committee and has not advanced, so Alaska has no statewide cost-allocation rule governing how a large data-center load is billed against other ratepayers.
