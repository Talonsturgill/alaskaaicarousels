# AUTOMATION RETRO — run 2026-08-28, Carousel No. 43

## THE STANDING REPEAT OFFENDER, and what this run did with it

`trend_check --window 10` named ARTWORK CRAFT AND GENUINE DETAIL as the weakest
criterion in nine of the last ten runs, mean 6.75. This run WORKED ON IT rather
than deferring it, and the result is a genuine partial.

The attack was structural rather than exhortative. Every word in the deck sits
on a modelled object in the scene, a plywood datum board or an aluminium tag
with its own thickness, screws, weathering and two part contact shadow, so type
never lands on generated art and there is no scrim anywhere in six slides.

It worked on the thing it aimed at. The four warn classes that had recurred for
weeks, busy art under text, art touching glyphs, top loaded composition and
outside safe zone, went from four to one across the deck, and the survivor is
on a single slide. The scorer confirmed the carriers are the best crafted
furniture the deck has shipped in weeks.

It did not lift the score, and the reason is worth writing down. Craft came in
at 6.5, up from 6.0 on the first pass but still the criterion holding the deck
down. THE FAILURE MOVED RATHER THAN DISAPPEARING. The carriers got expensive
and the landscapes got cheap, so the dead zones the type used to sit on are now
in the ground behind it. That is a real finding about this attack and the next
run that tries it should budget for the background, not just the foreground.

## DEVIATIONS FROM THE MASTER ROUTINE, with evidence

- **Shipped six slides against a planned nine.** Degradation ladder step (b),
  declared with three slides on disk. Cause was build cost per slide, driven by
  the three engine traps below.
- **No pixel critics were spawned.** The routine's Phase 8 asks for one critic
  per one to two slides. The showrunner reviewed every render directly instead,
  and the machine gates plus the scorer carried the rest. This is a disclosed
  reduction in review rounds, ladder step (c), and it is why the scorer found
  defects a critic round would have caught earlier, notably slide 06's detached
  Polaris and slide 04's missing gold rule.
- **No flow critic.** Same cause. The showrunner read the contact sheet.
- **The scorer ran twice, which is the routine's design working.** The first
  pass found a real hard fail, the run went back to Phase 8, fixed it, and the
  second pass cleared. That is exactly what CLAUDE.md's "a low score is a work
  order" clause is for, and it is the first time this year the clause has been
  exercised end to end rather than argued with.
