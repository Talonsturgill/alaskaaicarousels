So the attack has three specific commitments, made here at planning altitude and
carried into every Phase 5 dossier:

1. **Every drawn object gets a surface pass with a named material.** Not one
   hero. Every object large enough to hold texture declares its finish (character,
   grain direction, scale) in dossier field 7 and gets the masked overlay pass.
   No untextured primitive ships.
2. **Every measured rect is measured off the render, not off the plan.** Every
   `data-encodes`, `data-contacts` and leader target is read from the rendered
   PNG and re-read whenever its object moves. Screen-space annotation that names
   a camera-placed object is DERIVED from that object's projected bounding box.
3. **The subject has to read as itself at 432px.** The deck's crux object gets a
   silhouette test in its dossier acceptance checklist, phrased so a critic can
   fail it, because that is the check No.38's slide 06 did not have.
